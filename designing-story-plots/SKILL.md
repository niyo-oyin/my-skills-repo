# Designing Story Plots

物語の「出来事の年表」ではなく、**「テーマの核」を「読者が体験する感情のうねり」へと変換する設計図（プロット・企画書）**を作成するスキル。

## Core Principles

プロット作成時は以下の5原則を徹底する。

1. **出来事より先に「思想と制約（やりたいこと）」を定義する**
   - いきなり第1話の展開から書かない。まず「描きたい価値観の対立」「世界観のリアリティライン」「想定ボリューム」を作品の憲法として明文化する。
   - 現代の倫理観で安易に善悪を裁かない。その世界の住人にとっての「当たり前」を基準に置く。
2. **「何が起きるか」ではなく「読者の感情の推移」を設計する**
   - プロット本文の随所にカッコ書き `（ここで〇〇な感情にさせたい）` を入れ、感情の落差（ワクワク→不安→安堵からの絶望→カタルシス→余韻）を明示する。
   - 不快な後味を避けたい箇所など、感情のガードレールも言語化する。
3. **キャラクターは「履歴書」ではなく「機能と対比」で作る**
   - 細かい趣味や生い立ちは省き、「読者の感情移入のしやすさ」「物語上の役割」「価値観の対比構造」を定義する。
   - **敵役（対立する側）を記号的な悪にしない。** そちら側なりの切実な動機・正義・日常のリアリティを与える。
4. **細部を「あえて曖昧にする」勇気と、着地点への執着**
   - 中盤の細かい理屈や繋ぎは「なんやかんやあって」「〜とか」と意図的に余白を残し、話の推進力を殺さない。
   - 一方で、「全体の大きなうねり」と「最終話の着地点・余韻」は明確に描き切る。
5. **「手触り」を既存のイメージで翻訳する**
   - 空気感やキャラ造形が伝わりにくい場合、「〇〇＋△△風」「部活ものの序盤みたいに」など、身近な職業やジャンル感の例えを用いて直感的に共有する。

## Workflow

ユーザーの依頼に応じて以下の手順で進める。

1. **要件の把握（不足があれば最大3点まで確認、お任せなら即座に仮定して進む）**
   - ジャンル（SF、歴史、サスペンス等）、想定のボリューム感、入れたいモチーフがあれば確認する。
2. **テンプレートの読み込みとドラフト作成**
   - 出力形式は [assets/plot-template.md](assets/plot-template.md) を参照し、原則に従ってプロットを執筆する。
3. **品質チェック（セルフレビュー）**
   - 出力前（または推敲依頼時）に [references/quality-checklist.md](references/quality-checklist.md) を読み込み、AI特有の「説明的すぎる・ご都合主義・記号的な敵役」に陥っていないか検証・修正してから提示する。

## Output Style

- 企画書・メモのような生々しさとリズム感を重視する（箇条書き＋カッコ書きの演出意図メモ）。
- 緻密な設定資料集ではなく、**「読んでいて面白さの骨格とゴールが見える設計図」**を目指す。
