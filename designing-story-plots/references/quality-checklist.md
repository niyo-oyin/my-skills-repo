# Plot Quality Checklist

プロットを提示する前に、以下の項目を検証し、引っかかる点があれば修正すること。

## 1. テーマとリアリティライン
- [ ] 「管理社会＝悪、自由＝善」のような、現代の価値観による安易な二元論になっていないか？
- [ ] その世界の一般市民が「今の社会（あるいは常識）の方がまともだ」と感じる説得力があるか？

## 2. 感情の設計（エモーション・デザイン）
- [ ] 単なる「〇〇が起きて、次に△△が起きた」という出来事の羅列になっていないか？
- [ ] 各幕の要所に、読者の感情をどう揺さぶるか（ワクワク、安堵からの絶望、胸の苦しさ、カタルシス）がカッコ書きで設計されているか？

## 3. キャラクターの機能と対比
- [ ] 敵役（対立側）に、読者が「そっちの言い分もわかる……」と苦しくなるほどの切実な正義や日常があるか？
- [ ] キャラクター設定が不要な履歴書（誕生日や細かい過去など）で肥大化していないか？

## 4. 抽象度と着地点のバランス
- [ ] SF設定やトリックの細かい整合性の説明に溺れて、ドラマの推進力が死んでいないか？（未確定の細部はあえて「〜とか」「なんやかんや」で抜いているか？）
- [ ] 最終話の「画」と「読後感（余韻）」が、ぼんやりせず鮮明に描かれているか？
